STEP 01
Create a New Project
Set up your Godot project folder and configure the renderer.
Project Setup
  1. Open Godot Engine — you'll land on the Project Manager screen.
  2. Click "New Project" in the top-right corner.
  3. Give it a name (e.g. MyPlatformer) and choose a folder on disk.
  4. Under Renderer, select Forward+ (Vulkan) for 3D, or Compatibility (OpenGL) for 2D/low-end. For this guide choose Compatibility.
  5. Click "Create & Edit" — the Godot editor opens.
Editor Layout Overview

Scene panel (top-left) — your scene tree of nodes.

Inspector (right) — properties of the selected node.

FileSystem (bottom-left) — your project files.

Viewport (centre) — what the game looks and feels like.

Tip: Save your scene early with Ctrl + S. Godot will ask you to name it — call it Main.tscn.
STEP 02
Understand Nodes & Scenes
Everything in Godot is a Node. Learn the two most fundamental concepts.
Core Concepts
  • Node — the basic building block. Every object (camera, sprite, sound) is a node with specific properties and behaviour.
  • Scene — a tree of nodes saved as a .tscn file. You can instance scenes inside other scenes (e.g., a Player scene inside your Level scene).
  • Script — a GDScript (or C#) file attached to a node to give it logic.
  • Signal — Godot's event system. Nodes emit signals (e.g., body_entered) that other nodes can connect to.
Key Node Types You'll Use
  • Node2D — base for all 2D objects. Has position, rotation, scale.
  • Sprite2D — draws a texture/image in 2D space.
  • CharacterBody2D — a physics body ideal for player characters.
  • CollisionShape2D — defines the hitbox of a physics body.
  • TileMapLayer — paint levels using a tileset.
  • Camera2D — follows the player, controls the viewport.
Godot 4 note: TileMap was replaced by TileMapLayer in Godot 4.3+. The concepts are identical.
STEP 03
Create the Player Scene
Build a CharacterBody2D player with a sprite and collision shape.
Build the Player Node Tree
  1. In the Scene panel, click the + icon (or press Ctrl+A) → search CharacterBody2D → Add.
  2. Rename this root node to Player (F2 or double-click).
  3. Add a child Sprite2D: select Player → Ctrl+A → Sprite2D.
  4. Add a child CollisionShape2D: select Player → Ctrl+A → CollisionShape2D.
  5. In the Inspector with CollisionShape2D selected, set Shape → New CapsuleShape2D (or RectangleShape2D). Resize to fit your sprite.
  6. Save this as its own scene: Scene → Save Scene As → Player.tscn.
Assign a Texture

In the Inspector with Sprite2D selected, drag an image from the FileSystem into the Texture property. Godot supports PNG, JPG, SVG. You can use Godot's built-in icon.svg as a placeholder.

STEP 04
Write Player Movement (GDScript)
Attach a script to the Player and implement gravity + WASD/arrow movement.
Attach a Script
  1. Select the Player root node in the Scene panel.
  2. Click the script icon in the toolbar (or press Ctrl+Shift+A).
  3. Keep the template as CharacterBody2D: Basic Movement — click Create.
Player.gd — Full Script
extends CharacterBody2D

# ── Constants ──────────────────────────────────────
const SPEED    = 200.0
const JUMP_VEL = -500.0
const GRAVITY  = 980.0

func _physics_process(delta: float) -> void:
    # Apply gravity when not on floor
    if not is_on_floor():
        velocity.y += GRAVITY * delta

    # Jump
    if Input.is_action_just_pressed("ui_accept") and is_on_floor():
        velocity.y = JUMP_VEL

    # Horizontal movement
    var dir = Input.get_axis("ui_left", "ui_right")
    if dir != 0:
        velocity.x = dir * SPEED
    else:
        velocity.x = move_toward(velocity.x, 0, SPEED)

    move_and_slide()
Default input actions: ui_left/ui_right = Arrow keys + A/D, ui_accept = Space + Enter. You can customise these in Project → Project Settings → Input Map.
STEP 05
Build a Level with TileMapLayer
Create platforms, ground, and walls using Godot's tile editor.
Create the TileMapLayer
  1. Open Main.tscn. Add a child node: TileMapLayer.
  2. In the Inspector, click Tile Set → New TileSet.
  3. At the bottom of the editor, the TileSet panel opens. Click the + to add an Atlas source — drag your tileset image in.
  4. Select tiles in the atlas and assign Physics Layer → New Physics Layer to give them collision.
  5. Switch to the TileMap tab at the bottom, select a tile, and paint your level in the viewport.
Add a Physics Layer to the TileMapLayer
  1. Select the TileMapLayer node → Inspector → Collision section.
  2. Set Collision Layer to 1 and Collision Mask to 1.
  3. Do the same for your Player (CharacterBody2D) so they interact.
Quick tileset: If you don't have art yet, search for "Kenney platformer tiles" — it's free, open-source, and works perfectly as a placeholder.
Instance the Player into Main.tscn
  1. In Main.tscn, click Scene → Instantiate Child Scene (or drag Player.tscn from FileSystem into the scene tree).
  2. Position the Player above your ground tiles in the viewport.
STEP 06
Camera & UI Setup
Make the camera follow the player and add a simple on-screen HUD.
Camera2D — Following the Player
  1. In Player.tscn, add a child Camera2D node to the Player.
  2. In Inspector, enable Enabled → On and set Zoom to (2, 2) for a closer view.
  3. Enable Position Smoothing → Enabled and set Speed to 5 for a smooth follow.
  4. Set Drag Horizontal/Vertical to add a lead offset (optional but feels great).
Simple HUD — CanvasLayer + Label
  1. In Main.tscn, add a CanvasLayer child — this keeps UI on screen regardless of camera.
  2. Add a Label child to the CanvasLayer. Set its text to "Score: 0" in the Inspector.
  3. In the Layout section, anchor it to Top Left and set Offset Left: 16, Offset Top: 16.
Score Script (Main.gd)
extends Node

var score = 0
@onready var score_label = $CanvasLayer/Label

func add_score(amount: int) -> void:
    score += amount
    score_label.text = "Score: %d" % score
STEP 07
Add a Collectible & Enemy
Create a coin collectible with Area2D and a basic patrolling enemy.
Coin Scene (Area2D)
  1. Create a new scene with root Area2D, rename to Coin.
  2. Add children: Sprite2D (texture = coin image) + CollisionShape2D (CircleShape2D).
  3. Attach Coin.gd:
extends Area2D

func _ready() -> void:
    body_entered.connect(_on_body_entered)

func _on_body_entered(body) -> void:
    if body.name == "Player":
        # Tell main scene to add score
        get_tree().get_root().get_node("Main").add_score(10)
        queue_free() # Remove coin from scene
Simple Patrolling Enemy
  1. Create a new scene: root CharacterBody2D → rename Enemy.
  2. Add Sprite2D + CollisionShape2D children.
  3. Attach Enemy.gd:
extends CharacterBody2D

const SPEED   = 80.0
const GRAVITY = 980.0
var direction = 1

func _physics_process(delta: float) -> void:
    if not is_on_floor():
        velocity.y += GRAVITY * delta

    # Flip direction on wall hit
    if is_on_wall():
        direction *= -1

    velocity.x = direction * SPEED
    move_and_slide()
Instance both Coin.tscn and Enemy.tscn into Main.tscn by dragging from the FileSystem panel. Place coins on platforms and enemies on patrol paths.
STEP 08
Test, Export & Next Steps
Run your game, export it, and where to go from here.
Running Your Game
  • Press F5 (or the ▶ Play button) to run the project. Godot will ask for a main scene — choose Main.tscn.
  • Press F6 to run only the currently open scene (useful for testing individual scenes).
  • Press F8 or close the window to stop. Check the Output panel at the bottom for print statements and errors.
Exporting (Web / Windows / Mac / Linux)
  1. Go to Project → Export.
  2. Click Add… and choose your platform (e.g., Web, Windows Desktop).
  3. If prompted, download the Export Templates via the provided link (one-time download).
  4. Set your output path, then click Export Project. Done — a playable binary or HTML5 build is generated.

What to Learn Next
  • AnimationPlayer — for sprite sheet animations (walk, jump, idle).
  • AudioStreamPlayer — add background music and sound effects.
  • Scene switching — get_tree().change_scene_to_file("res://GameOver.tscn") for game over screens.
  • Autoload / Singleton — a global script for score, settings, save data.
  • Shader — visual effects like screen flash, outlines, pixelation.
  • GDUnit4 / gut — unit testing your GDScript logic.
